# 주차 교차전이 week2-week3

## 핵심 요약
수집시점 드리프트 통과 실험 — 정체성 피처 없이 seq 행동피처(seq-core 299/N60)만으로 week2↔week3(LAB 프로세스) 전이. 공통 74프로세스, LightGBM(core 튜닝). **within(같은 주차)은 F1 ~73으로 강건하나, 시점 넘어가면 대폭 하락**(w2→w3 −32, w3→w2 −14). Acc는 덜 떨어짐 → 흔한 프로세스는 전이되나 **희소 프로세스가 시점 따라 드리프트**. compact N60 ≈ 299(전이서도 압축 유지). 관련: [[피처 정립·seq-core]], [[PRISM(LAB) 데이터·진단]], [[앙상블 Bias-Variance·튜닝]]

## 기록

### 교차전이 실측 (299 / N60)  <!-- (2026-08-24) -->
- 코드: `01_code/transfer_week.py` + `run_transfer_week.sh`. 산출 `03_json/transfer_week_{299,N60}.json`.
- 공통클래스 74(week2·week3 양쪽 ≥10 생존분). week2 602,960행 · week3 1,488,777행.
- LightGBM core 튜닝값, 피처 양쪽 동일 파이프라인(K30 + FEAT_SELECT). CPU(GPU 대용량 다중클래스 크래시 이력).

**macro-F1 / Acc:**

| 피처 | within-w2(상한) | within-w3(상한) | w2→w3 | w3→w2 |
|---|---|---|---|---|
| 299 | 73.31 / 88.94 | 71.77 / 84.63 | **40.99 / 58.86** | **58.70 / 78.24** |
| N60 | 72.98 / 88.52 | 71.13 / 83.89 | 42.45 / 59.99 | 58.42 / 78.14 |

- **드리프트 실재**: 시점 넘으면 F1 대폭↓. w2→w3(41)은 −32, w3→w2(59)는 −14.
- **방향 비대칭**: w3→w2 ≫ w2→w3. week3 학습량 2.5배(149만 vs 60만) + week2 테스트가 더 쉬움 추정.
- **Acc는 덜 하락**(macro-F1 대비): 흔한 프로세스는 시점 넘어도 맞힘, 희소 프로세스가 행동·분포 드리프트 → macro-F1 집중 타격. → [[PRISM(LAB) 데이터·진단]] 희소클래스 진단과 직결.
- **압축 강건**: N60이 299와 전이 성능 거의 동일 → compact core가 시점 넘어도 안 깨짐(피처정립 "전이강건성 미검증" 갭 일부 해소).
