# LLM API 요금·무료한도 비교

## 핵심 요약
우리 실험 문항 1개(= 3조건 호출)의 **실측 토큰은 입력 약 273 / 출력 약 3,420**이다.
출력이 압도적인 이유는 답이 한 글자인데도 **추론 토큰이 출력으로 과금**되기 때문이다(평균 1,132 토큰/콜).
무료 API 등급이 있는 곳은 **Gemini 뿐**이다. Anthropic·OpenAI는 공식 요금 페이지에 무료 등급이 없다.
가격 확인일 2026-11-16. 관련: [[BAZE 게이트웨이 vs Gemini 직결 — 수집 환경 비교]], [[암호화 트래픽 Reasoning Effort 탐지 — 연구설계]]

## 기록

### 우리 실험의 실측 토큰량  <!-- (2026-11-16) -->
출처는 두 갈래 로그다. 입력 토큰은 게이트웨이 경로만 `input_tokens`를 기록하고(`out/openai_strict_v2s340_log.jsonl`, n=1,020),
추론 토큰은 직결 경로만 `thoughts_tokens`를 준다(`out/gem_strict_v2rest1~3_log.jsonl`, n=1,321).
같은 모델(`gemini-3.5-flash-lite`)·같은 문항이라 두 값을 합쳐 쓴다.

- 입력: 평균 91.4 토큰, 중앙값 81, 범위 66~176. 조건별 차이 없음(91.8 / 90.8 / 91.8) — 패딩 통제가 토큰 수준에서도 유지된다는 뜻.
- 출력(답): low 1.4 / medium 2.5 / high 10.2 토큰. 답이 한 글자라 거의 0에 가깝다.
- 추론: low 평균 268(중앙값 0) / medium 1,092(726) / high 2,046(1,213).
- **과금되는 출력 = 추론 + 답**: low 269 / medium 1,095 / high 2,056, 3조건 평균 1,140.

즉 **비용의 99%가 추론 토큰**이다. 답 길이를 줄이는 최적화는 이 실험에서 의미가 없다.

### 문항당 과금액 (3조건 1회씩)  <!-- (2026-11-16) -->
문항 1개 = 입력 274 토큰 + 출력 3,420 토큰.

- **Gemini 3.5 Flash-Lite** ($0.30 / $2.50): 입력 $0.00008 + 출력 $0.00855 = **약 $0.0086/문항**.
  전체 821문항이면 **약 $7.1**(2,463콜). 무료 등급이면 $0.
- **Claude Haiku 5.5** ($0.10 / $0.50): 약 $0.0018/문항, 821문항 **약 $1.4**. 셋 중 가장 싸다.
- **Claude Sonnet 5.5** ($2 / $10): 약 $0.0348/문항, **약 $28.6**.
- **Claude Opus 5.5** ($4 / $20): 약 $0.0695/문항, **약 $57.1**.
- **OpenAI gpt-6-luna** ($0.10 / $0.50): **실측 $0.00023/문항, 821문항 $0.19.** 아래 전용 항목 참고 — 추론량이 Gemini의 1/12라 추정치($1.4)보다 7배 싸다.
- **OpenAI gpt-5-nano** ($0.05 / $0.40): 약 $0.0014/문항, **약 $1.1**.

같은 문항에서 Claude가 몇 토큰을 생각할지는 **측정한 적이 없다**.
gpt-6-luna를 실측해보니 추정이 **7배 틀렸다**(아래 항목). Claude도 같은 크기로 틀릴 수 있다.

### 추론 토큰 과금 근거  <!-- (2026-11-16) -->
- Gemini: 공식 요금표의 출력 행 제목이 **"Output price (including thinking tokens)"**다. Gemini 4 계열에는
  "Every token the model processes is counted and billed, including thinking tokens" 문구가 따로 붙어 있다.
- Anthropic·OpenAI: 요금 페이지에 **추론 토큰 과금 여부가 명시돼 있지 않다**(확인 실패). 업계 관행상 출력으로 치지만 문서로 확인하지 못했다.

**용어 주의: 문항 = 질문 1개이고, 질문 1개는 API 호출 3번이다**(low·medium·high 각 1회).
821질문 × 3설정 = 2,463콜. 위 "821문항" 금액은 전부 이 2,463콜의 총액이다.
콜 1번 단위로 더 쪼개면 설정마다 다르다 — Gemini 실측 기준 low 0.07c / medium 0.28c / high 0.52c.
**high 가 low 의 7배다.** 설정 하나 바꾸는 것이 비용을 7배로 만든다.

주의 넷:
1. **Gemini 3.8 Flash 는 프로모 가격.** 2027-01-01 부터 $1.50 / $7.50 로 2배가 된다. 위 숫자도 2배로 봐라.
2. **"Gemini Pro" 의 현행 요금을 못 찾았다.** 공식 페이지에 3.5 Pro·3 Pro 텍스트 모델이 없다.
   위 값은 Gemini 3.1 Pro Preview 의 ≤200k 프롬프트 가격이고, 그마저 페이지 요약부에서 나온 값이라 **verbatim 이 아니다.**
3. **모델이 크다고 더 많이 생각하지 않는다.** luna(작음) high 평균 162토큰, Flash-Lite(작음) high 2,046토큰.
   12배 차이가 모델 크기가 아니라 **프로바이더 정책**에서 온다. 그래서 OpenAI 계열은 "적음" 열,
   Gemini 계열은 "많음" 열이 맞을 가능성이 높다 — 다만 **확인 안 했다.**
4. **Claude 는 저장소에 호출 경로가 아예 없다.** Gemini 네이티브와 OpenAI 호환 두 갈래뿐이다
   (`openai_capture_run_strict.py` 의 `--base_url`). Anthropic 러너를 새로 만들고 유료 키를 넣어야 한다. 무료 등급도 없다.

#### 돈이 아니라 신호가 기준이다
전수 비용이 전부 $7 이하다. **선택 기준은 가격이 아니라 단계 간 격차**다.
문항 하나 안에서 low~high 추론 토큰 격차를 재면:

| 모델 | 문항수 | 격차 중앙값 | >=100 비율 | low>high 역전 |
|---|---|---|---|---|
| Gemini 3.5 Flash-Lite | 379 | **1,160** | 100% | 1% |
| Groq gpt-oss-120b | 114 | 192 | 97% | 0% |
| Groq gpt-oss-20b | 114 | 168 | 93% | 0% |
| gpt-6-luna (low/med/high) | 53 | **26** | 28% | 19% |
| gpt-6-luna (none~max 6단계) | 53 | 105 | 53% | — |

MIN_SPREAD=100 근거는 추론 1토큰 ≈ 응답 4바이트, 100토큰 ≈ 400B ≈ 기준선의 30% 라는 것이다
([[암호화 트래픽 Reasoning Effort 탐지 — 연구설계]]).
**gpt-6-luna 는 3조건으로는 이 기준을 못 넘는다.** 쓰려면 none~max 로 벌려야 하고, 그래도 중앙 105로 턱걸이다.
Gemini 가 격차 1,160으로 압도적이다 — 지금 주력을 Gemini 직결로 잡은 것은 비용이 아니라 이 숫자 때문에 옳다.

**비교의 한계:** 문항셋이 다르다(Gemini v2 / luna hard / Groq 초기 30문항).
모델 차이와 문항 난도 차이가 섞여 있다. Groq 30문항은 선별을 거친 것인지 확인하지 못했다 —
거쳤다면 93~97% 통과율은 순환논리다. 엄밀히 하려면 같은 셋으로 다시 재야 한다.

### 무료 등급  <!-- (2026-11-16) -->
**Gemini — 있다.** 이게 지금 우리가 쓰는 것.
- `gemini-3.5-flash-lite` Free Tier: 입력·출력 모두 "Free of charge". 컨텍스트 캐싱은 무료에서 "Not available".
- 무료인 모델: 3.5 Flash-Lite, 4 Hydrogen, 3.8 Flash, 3.6 Flash, 3.5 Transcribe 계열.
- 무료 **아닌** 모델: Gemini 4 Carbon, 4 Argon, 3.1 Pro Preview, Omni 1.2 Flash, Nano Banana 계열.
- **대가: 무료 등급은 "Content used to improve our products"**. 유료 등급은 "not used". 우리 문항은 공개 퍼즐이라 상관없지만, 민감 데이터는 무료로 보내면 안 된다.
- 일일 한도: 공식 rate-limits 페이지에 텍스트 모델의 RPM/TPM/RPD 표가 **없다**("AI Studio에서 확인하라"고만 함).
  우리가 429 에러로 **직접 확인한 값이 더 정확하다**: `GenerateRequestsPerDayPerProjectPerModel-FreeTier`, `quotaValue: 500`.
  **토큰이 아니라 콜 수로 센다. 모델별·프로젝트별로 따로 센다.** RPD는 태평양시 자정에 리셋.
- 등급 승급: Tier 1 = 결제계정 연결, Tier 2 = $100 결제 + 3일, Tier 3 = $1,000 결제 + 30일.

**Anthropic — 없다.** 요금 페이지에 무료 등급 항목이 없다. 있는 것은:
- 신규 가입자에게 주는 **free credits**("New users receive free credits to test the API"). **금액은 문서에 안 적혀 있다.**
- Max 플랜 월 $100 / Ultra 월 $200의 API 크레딧 — 구독 혜택이지 무료 등급이 아니다.
- 비용 절감 수단은 따로 있다: Batch API **50% 할인**, 프롬프트 캐시 읽기 0.1배(Opus 5.5·Sonnet 5.5는 0.05배).
  우리 실험은 문항마다 프롬프트가 달라 캐시 효과가 거의 없고, Batch는 **시간 측정이 불가능**해 못 쓴다.

**OpenAI — 없다.** 요금 페이지에서 무료로 표시된 것은 `omni-moderation-latest` 하나뿐이다.
"데이터 공유하면 무료 토큰" 프로그램도 **페이지에서 확인하지 못했다**(과거에 있었으나 현행 여부 미확인).
`gpt-6.1-terra`는 2026-11-30까지 프로모션 가격이라 12월부터 오른다.

**Groq — 무료 플랜 표시는 있으나 내용을 확정하지 못했다.**
- 요금: `openai/gpt-oss-20b` $0.075 / $0.30, `openai/gpt-oss-120b` $0.15 / $0.60 (console.groq.com/docs/models).
  groq.com/pricing 에는 표가 없다.
- rate-limits 페이지에 "Free Plan" 탭이 있지만, 본문은 같은 표를 "Developer plan 기준"이라 설명한다. **어느 쪽 수치인지 모호하다.**
  표상 두 gpt-oss 모델 모두 RPM 30 / RPD 1K / TPM 8K / TPD 200K. 무료 한도로 단정하지 말 것.
- 학습 사용 여부: **문서에서 찾지 못했다.** "By default, Groq does not retain customer data for inference requests" 와
  남용 감시용 로그 30일 보관 언급만 있고, 모델 학습이나 무료 등급 얘기는 없다.
- 추론 토큰 과금 여부도 문서에 없다. 단 우리 로그에서 `output_tokens` 가 추론을 포함하는 것이 확인되므로 실질적으로 출력 과금이다.

### 결론 — 어디서 돌릴 것인가  <!-- (2026-11-16) -->
- 데이터 **양**이 목적이면 Gemini 무료 등급이 유일한 답이다. 하루 500콜 = 문항 166개/일.
- **모델을 늘리는 것**(Task C)이 목적이면 Claude Haiku 5.5 또는 gpt-6-luna가 821문항당 **$1~2**다. 자비로 감당 가능한 수준.
- 비싼 모델(Opus 5.5 $57, Sonnet 5.5 $29)은 전수로 돌릴 이유가 없다. 쓴다면 **문항 일부만 표본**으로.

#### 배분과 순서
**랩비 10만원($70)은 전부 Anthropic.** OpenAI는 위 크레딧으로 충당되므로 랩비를 쓸 이유가 없다.
Claude는 전수 폭이 $1.4(Haiku)~$57(Opus)로 넓고 **전부 미측정**이라 $70을 다 쿠션으로 쓴다.

순서가 뒤집혔다. **OpenAI를 먼저 끝낸다** — 크레딧이 11-23에 죽기 때문이다.
Anthropic은 랩비에 (확인되지 않은) 만료가 걸리기 전까지 시간이 있고, 러너부터 써야 해서 어차피 늦다.

1. **스크리닝 먼저. 전수부터 돌리지 마라.** gpt-6-luna가 3조건 격차 중앙값 26토큰으로 탈락한 전례가 있다
   (MIN_SPREAD=100 기준, 19%는 low>high 역전). Claude도 같은 꼴일 수 있다.
2. 격차 100을 넘긴 모델만 전수.
3. **Opus 5.5와 astra는 전수하지 말고 표본만.** 전수하면 각각 예산의 80%, 200%다.

**기한: `gpt-6.1-terra`는 2026-11-30까지 프로모 가격이다.** terra 스크리닝은 그 전에 끝내고,
통과하면 프로모 기간 안에 전수까지 밀어넣어라.

#### 한 곳에 몰아서 둘 다 쓸 수 있나
**직결로는 안 된다.** Anthropic Console과 OpenAI Platform은 별개 회사·별개 잔액이다.
가능한 방법은 중계 게이트웨이(OpenRouter·BAZE 류) 하나로 묶는 것뿐이고,
OpenAI 호환이라 **Anthropic 러너도 필요 없어진다**는 이점이 있다.

**그런데 이번 목적에는 못 쓴다.** 게이트웨이는 추론 토큰을 안 준다(BAZE 실측 1,020/1,020 `null`).
스크리닝에서 재려는 값이 바로 그 숫자다. Configured(보낸 설정)와 총 지출액은 알 수 있지만
**Realized(실제 추론 토큰)는 못 잰다.** 관련: [[암호화 트래픽 Reasoning Effort 탐지 — 연구설계]]

단, **과금이 토큰 비례라면 차감액에서 토큰 수를 역산할 수 있다.** 콜당 고정 요금이면 불가능하다.
같은 조건으로 몇 콜 날려보고 차감액이 서로 다른지만 보면 구분된다 — 아직 확인하지 않았다.

- **게이트웨이 과금 방식**(토큰 비례 / 콜당 고정). 위 역산 가능 여부가 여기 달려 있다.

#### Anthropic 실측 — 러너 완성, 추론 토큰 온다, 크레딧 $40 이 제약  <!-- (2026-11-18) -->

**추론 토큰은 `usage` 에 온다** — `output_tokens_details.thinking_tokens`.
게이트웨이(BAZE)와 달리 라벨이 있으므로 Task B 가 성립한다.
**`output_tokens` 에 추론이 포함된다**(576 중 573). 과금은 이 값 그대로 계산하면 된다.

**실측 (claude-opus-5-5, 40콜):** 입력 106토큰/콜, 출력 403토큰/콜.
단 이 40콜은 `knight_path` 한 갈래다. 같은 날 OpenAI luna 로 갈래 19개를 섞어 재보니
섞인 표본이 한 갈래보다 **1.5배** 높았다(337 → 500). Opus 도 섞으면 600 근처로 오를 수 있다.

| claude-opus-5 | 5 / 25 | $27.1 | $40 |
| claude-sonnet-5-5 | 2 / 10 | $10.9 | $16 |

**opus-5 는 뺀다.** Task C(모델 식별)에서 값어치 있는 대비는 **티어 간**이지 세대 간이 아니다.
