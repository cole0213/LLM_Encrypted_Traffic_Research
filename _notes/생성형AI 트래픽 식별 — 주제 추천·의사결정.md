# 생성형AI 트래픽 식별 — 주제 추천·의사결정

상위: [[생성형AI 트래픽 식별]] · [[02_SGS]] · 근거: [[생성형AI 트래픽 식별 — baseline 문헌분석]]

## 핵심 요약
16편(baseline 13 + 행동 3) 정독 근거로, 후보 축 L1~L6 중 **가장 좋은 연구 주제를 추천**하고 각 축의 선행연구 성숙도·한계·논쟁을 정리(2026-09-01). 결론: **L4 작업 단계 추론이 최적**.

## 추천: L4 작업 단계 (단순질문 vs 긴 추론 vs 도구 사용)
초반은 **L3 음성**을 "확실한 승리"로 먼저 검증하고, **L4로 신규성**을 박는 2단 전략.

**왜 L4가 최적 — 신규성 × 실현성 × 근거의 교집합:**
- **신규성 최고** — 트래픽으로 추론 깊이·도구사용을 라벨한 논문 없음. "From Prompts to Packets"가 reasoning 모델을 명시적으로 배제 = 깨끗한 빈 땅.
- **근거 있음(실현 가능)** — Time Will Tell(출력 토큰수로 태스크 유형 누출), Remote Timing(easy vs hard 쿼리 2배 타이밍차), Voice Fingerprinting(서버 응답 결정론적 → 인커밍만으로 콘텐츠 구분).
- **시의성** — o1/o3·extended-thinking이 2024~2026 신문물, 선점 타이밍.
- **논지 정합** — 서비스 무관 일반화(행동 > 서비스명), 이상탐지로 확장.

**왜 L2·L5가 아니라 L4:** L2(에이전트 유형)·L5(자율성)는 신규성은 같거나 높지만 "가능한지"부터 불확실 + 데이터 난도 훨씬 큼(자율에이전트 세션을 실제로 돌려 캡처해야). L4 = 신규성 충분 + 근거 있음 + 데이터 현실적 = 스위트스팟.

## 후보별 선행연구 성숙도

| 축 | 선행연구 성숙도 | 신규성 | 판정 |
|---|---|---|---|
| L1 GenAI 탐지 | 성숙 (From-Prompts, WFP 일반) | 낮음 | 워밍업용 |
| L2 에이전트 유형 | 거의 없음(트래픽); AgenTag은 코드 | 최고 | 고위험 |
| L3 모달리티 | 음성=성숙(2020~ 확립), 이미지/텍스트=얕음 | 중 | 초반 승리 |
| **L4 작업 단계** | **거의 없음 + 간접근거 강함** | **최고** | **★ 주력** |
| L5 자율성 | 거의 없음 | 최고 | 최고위험 |
| L6 보편성·드리프트 | 방법론 축(항상 필요) | — | 차별화 도구 |

## 5가지 분석 (필드 전체 → L4 관점 해석)

### ① 공통 향후 과제·한계
- **시간 드리프트(전 논문 공통, 미해결):** AgenTag Claude Code F1 0.43 붕괴, Remote Timing 서명 한 달 뒤 붕괴, ET-BERT/DF/Voice 전부. → L4서도 최대 리스크(추론 서명이 모델 업데이트로 이동).
- **reasoning 모델 미포함:** From-Prompts 명시 배제 = 정확한 개구부.
- **합성/통제 데이터 실환경 괴리:** Voice(자동 TTS), Whisper Leak("하한" 규정).
- **open-world 미지 대응 미흡 + SNI-free 순수행동 이전 미검증.**

### ② 구조적 결함·계산 병목
- **[최대] per-packet split 데이터누수(Sweet Danger):** ET-BERT/YaTC 98%가 인위적(암시적 flow-ID shortcut). per-flow시 ~40%, 랜덤초기화도 동성능. → 실험을 처음부터 per-flow split으로.
- **SNI/payload shortcut 의존:** From-Prompts는 SNI 가리면 −20%p. → SNI 빼고도 되는지가 차별점.
- **task-stage 신호를 라벨로 안 씀 = 구조적 부재:** 기여 여지 그 자체.
- **자기회귀 스트리밍 = 부채널 근원(내재):** 완화 근본적으로 어렵고 효율추론(speculative decoding)이 오히려 누출 증가 → L4에 유리.
- **표현학습 비효율:** shallow ML이 동등/우수한데 최대 2048배 느림.

### ③ 미해결 논쟁 (학계 합의 안 됨)
- **행동 vs 서비스명** — 무엇이 진짜 신호? → 우리 논지가 한 답.
- **관측면:** 에이전트 정체가 코드/PR(AgenTag) vs 패킷(네트워크) — 상보적이나 우열 미합의.
- **SNI 써도 되나** — 현실적(From-Prompts) vs 신규성(SNI-free, 우리).
- **딥러닝 값어치** — Sweet Danger(NO) vs 표현학습 라인(YES).
- **트래픽 = 언어/이미지/그래프** (ET-BERT vs YaTC vs TFE-GNN).
- **메타데이터 누출 방어 가능한가** — Whisper Leak(불가) vs Remote Timing(constant-rate 가능, 대역폭 대가) → L4 시그니처가 벤더 완화에 견디나가 리스크.

## 한 줄 결론
> **L4 작업단계(추론깊이·도구사용)를 SNI-free·per-flow로 하는 게 최적.** 선행연구가 정확히 이 지점(reasoning 배제·SNI 의존·행동 라벨 부재)을 비워뒀고 간접근거는 탄탄. L3 음성으로 "된다"를 먼저 보이고 L4로 신규성을 박는 2단 전략.

## 후보 축 정의 (L1~L6)
- **L1 GenAI 트래픽 여부** — 이 flow가 생성형 AI 서비스와 통신 중인가(vs 일반 웹·스트리밍·API). 가장 상위의 탐지.
- **L2 에이전트 유형** — 어떤 종류의 에이전트 행동인가: 대화형 챗봇 vs 코딩 에이전트(Copilot·Cursor·Claude Code) vs 리서치 에이전트(딥리서치·웹브라우징). 서비스명이 아니라 행동으로.
- **L3 출력 모달리티** — 텍스트 vs 이미지 vs 음성 생성.
- **L4 작업 단계/복잡도** — 단순 질문 vs 긴 추론(extended thinking) vs 도구 사용.
- **L5 배포·자율성** — 로컬 모델 vs 클라우드 API / interactive user vs autonomous agent.
- **L6 보편성·드리프트** — 만든 분류기가 네트워크 환경(가정·모바일·VPN)·시점(모델·UI 변경)을 넘어 일반화되나. 방법론적 검증 축.
